获取用户输入信息

说明

本章节将介绍如何通过命令行与用户进行交互以取得输入信息，如获取用户输入的一个实数，字符串，关键字等。

用户输入函数介绍

下面表格列举了各种获取用户输入信息所需的函数，后续文章将逐一演示如何使用这些函数。

函数名 作用 参数
zcedGetReal() 提示用户输入一个实数 zds_real
zcedGetInt() 提示用户输入一个整数 int
zcedGetKword() 提示用户输入关键字 TCHAR
zcedGetString() 提示用户输入一个字符串 TCHAR

获取一个实数zcedGetReal()

void getReal()
{
	zds_real dReal;
	if (zcedGetReal(_T("\nInput a real number:"), &dReal) == RTNORM)
		zcutPrintf(_T("\nThe real number is %g"), dReal);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用户输入一个实数"Input a real number:"，如果用户输入10.2，最终命令行输出“The real number is 10.2”。

获取一个整数zcedGetInt()

void getInt()
{
	int nRet;
	if (zcedGetInt(_T("\nInput a Integer:"), &nRet) == RTNORM)
		zcutPrintf(_T("\nThe Integer is %d"), nRet);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用户输入一个整数"Input a Integer:"，如果用户输入10，最终命令行输出“The Integer is 10”。

获取一个关键字zcedGetKword()

void getKWord()
{
	TCHAR keyWord[10] = { 0 };
	zcedInitGet(0, _T("A B C D"));
	int retVal = zcedGetKword(_T("Input KeyWord [Branch A(A)/Branch B(B)/Branch C(C)/Branch D(D)] : "), keyWord);
	if (retVal == RTNORM)
	{
		if (_tcscmp(keyWord, _T("A")) == 0)
			zcutPrintf(_T("\nThis is Branch A"));
		else if (_tcscmp(keyWord, _T("B")) == 0)
			zcutPrintf(_T("\nThis is Branch B"));
		else if (_tcscmp(keyWord, _T("C")) == 0)
			zcutPrintf(_T("\nThis is Branch C"));
		else if (_tcscmp(keyWord, _T("D")) == 0)
			zcutPrintf(_T("\nThis is Branch D"));
	}
	else if (retVal == RTCAN)
		zcutPrintf(_T("\nYou have cancelled!"));
	else if (retVal == RTNONE)
		zcutPrintf(_T("\nYou Have not input, and the default is Branch D"));
}

运行结果：

执行命令提示用户输入一个关键字"Input KeyWord [Branch A(A)/Branch B(B)/Branch C(C)/Branch D(D)]:"，如果用户输入B，最终命令出“This is Branch B”。

获取一个角度zcedGetString()

void getString()
{
	TCHAR szStr[1024] = { 0 };
	if (zcedGetString(0, _T("\nInput a string:"), szStr) == RTNORM)   // If first parameter is not 0, you can input the Space
		zcutPrintf(_T("\nThe string is %s"), szStr);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用户输入一个字符串"Input a string:"，如果用户输入hello，最终命令行输出“The string is hello”。
