程序入口与命令注册

示例代码解析

在前面的章节《第一个ZRX程序》中，我们提及到了如下示例代码：

#include "pch.h"
#include "zadsmigr.h"
#include "zadsdef.h"
#include "zadscodes.h"
#include "zacestext.h"
#include "zacedads.h"

void helloworld()
{
	zcutPrintf(_T("\nHello world!"));
}

void initapp()
{
	zcedRegCmds->addCommand(cmd_group_name, _T("helloworld"), _T("helloworld"), ZCRX_CMD_MODAL, helloworld);
}

void unloadapp()
{
	zcedRegCmds->removeGroup(cmd_group_name);
}

extern "C" ZcRx::AppRetCode zcrxEntryPoint(ZcRx::AppMsgCode msg, void* appId)
{
	switch (msg)
	{
	case ZcRx::kInitAppMsg:
	{
		zcrxDynamicLinker->unlockApplication(appId);
		zcrxDynamicLinker->registerAppMDIAware(appId);
		initapp();
	}
	break;
	case ZcRx::kUnloadAppMsg:
	{
		unloadapp();
	}
	break;

	default:
		break;
	}
	return ZcRx::kRetOK;
}


#ifdef _WIN64
#pragma comment(linker, "/export:zcrxEntryPoint,PRIVATE")
#pragma comment(linker, "/export:zcrxGetApiVersion,PRIVATE")
#else // WIN32
#pragma comment(linker, "/export:_zcrxEntryPoint,PRIVATE")
#pragma comment(linker, "/export:_zcrxGetApiVersion,PRIVATE")
#endif

这是一个最简单的中望CAD ZRX二次开发程序，在这段示例代码里面做了三件事，一是对zcrxEntryPoint和zcrxGetApiVersion，二是定义了命令对应函数helloworld，函数中zcutPrintf(_T("\nHello world!"));语句为在命令行输出“Hello world”字符串；三是在类initapp()中定义了命令helloworld。

接下来我们将详细介绍这段代码每一个部分的作用。

头文件

头文件都是一些常用头文件，如果不清楚需要添加哪些头文件可以在pch.h头文件中直接添加“zarxHeaders.h"几乎能涵盖绝大部分开发场景，如果开发过程中还有某些接口找不到头文件等问题，可以通过开发参考手册中查询。

zcrxEntryPoint入口函数

ZRX应用程序是一个DLL，因此它没有主函数main()，ZWCAD调用ZRX模块的zcrxEntryPoint()函数来传送消息到应用程序中，ZWCAD通过调用这个函数来通知ZRX应用程序各种事件和消息。

参数说明：

msg:一个枚举值，表示ZWCAD发送给ZRX应用程序的消息类型。

pkt:一个指向消息相关数据的指针，内容取决于msg参数的值。

主要作用：

消息类型 功能介绍
kInitAppMsg ZRX应用程序被加载。
kUnloadAppMsg ZRX应用程序被卸载。
kLoadDwgMsg 图形文件被加载。
kUnloadDwgMsg 图形文件被卸载。
kInvkSubrMsg 调用ZRX定义的命令。
kPreQuitMsg ZWCAD即将退出。

initapp()和unloadapp()

initapp()方法

作用：实际上这里它只做一件事情，就是使用ZWCAD的命令机制注册一个新命令。这个命令同ZWCAD的内部命令一样，可以直接在命令行中执行。实际上，这就是运行ZRX程序的方法。

unloadApp()方法

作用：该函数会从ZWCAD中删除被定义的命令组cmd_group_name宏定义对应的字符串，此后就不能再调用所定义的命令了。前面在initApp()函数中注册了外部函数，在卸载程序时自然要将其删除。

命令注册

	virtual Zcad::ErrorStatus addCommand(const ZTCHAR * cmdGroupName,
                                     const ZTCHAR * cmdGlobalName,
                                         const ZTCHAR * cmdLocalName,
                                         ZSoft::Int32 commandFlags,
                                         ZcRxFunctionPtr FunctionAddr,
                                         ZcEdUIContext *UIContext = NULL,
                                         int fcode = -1,
                                         HINSTANCE hResourceHandle=NULL,
                                         ZcEdCommand** cmdPtrRet = NULL) = 0;

参数说明：

cmdGroupName：组名，命令编组名称。中望CAD的命令通过不同的命令编组名称进行统一管理。

cmdGlobalName：命令的全局名称（英文名称），在ZWCAD命令行中输入的英文命令名。

cmdLocalName：本地名称，类似cmdGlobalName参数，不过这里指定的是本地命令名称，方便二次开发程序进行多语言本地化。

FunctionAddr：指向命令处理函数的指针，函数必须符合 int func()的原型。

fcode：为命令指定一个整数标识码，用于区分不同命令，可用于命令的序列化或脚本处理。

resourceInstance：指定本地化资源的来源，当命令需要从资源DLL加载本地化字符串时使用，支持多语言应用程序开发。

commandFlags：定义命令的行为。以下为commandFlags类型部分常用值的介绍：

枚举值 功能介绍
ZCRX_CMD_MODAL 将命令设置为模态命令，即该命令只能在当前活动的文档中进行操作，且当其他命令运行时，此命令无法执行。
ZCRX_CMD_SESSION 将命令运行级别设置为应用程序级别，而不是当前图形文档级别。当命令需要跨多个文档执行或需要在没有打开任何文档时执行使用。当要对文档内容进行修改时，需要使用zcDocManager->lockDocument方法锁定文档。
ZCRX_CMD_TRANSPARENT 允许命令作为透明命令运行，即在执行其他命令的过程中可以运行此命令。
ZCRX_CMD_USEPICKSET 允许命令使用用户之前选择的对象集作为输入。需要获取用户执行命令时已选中的对象时使用。
ZCRX_CMD_NOPAPERSPACE 禁止从图纸空间使用此命令。
ZCRX_CMD_NOTILEMODE 当TILEMODE系统变量设置为1时，禁止使用该命令。

zcrxEntryPoint和zcrxGetApiVersion导出

#ifdef _WIN64
#pragma comment(linker, "/export:zcrxEntryPoint,PRIVATE")
#pragma comment(linker, "/export:zcrxGetApiVersion,PRIVATE")
#else // WIN32
#pragma comment(linker, "/export:_zcrxEntryPoint,PRIVATE")
#pragma comment(linker, "/export:_zcrxGetApiVersion,PRIVATE")
#endif

这是Windows动态链接库创建输出函数的一种方式，也就是说通过导出这两个函数通知ZWCAD输出了哪些函数，以便执行入口函数。另外也可以使用.def模块定义文件来做函数导出：

LIBRARY	""

EXPORTS
zcrxEntryPoint PRIVATE
zcrxGetApiVersion PRIVATE
