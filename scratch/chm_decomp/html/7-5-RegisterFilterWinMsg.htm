钩子函数

上一节提到了我们对特定实体添加了双击协议，使得我们双击该实体时会执行自定义的操作。但是有时我们可能还需要对鼠标不同的按键进行更多的处理，例如鼠标滚轮滚动、按下鼠标中键等行为，故此时我们就需要使用到钩子函数，该函数可以获取到更完整的键盘鼠标输入消息。

注册钩子函数

有两种接口可以注册钩子函数，分别为zcedRegisterFilterWinMsg和zcedRegisterWatchWinMsg，两者使用方式类似，区别如下：

接口 作用
zcedRegisterFilterWinMsg 传递给应用程序的消息可以被修改，并且可以被阻止。
zcedRegisterWatchWinMsg 此函数只能查看ZWCAD的Windows消息，不能更改或阻止消息。 
bool filter(MSG *pMsg) 
{
    // 判断当前是否为滚轮消息
    if (pMsg->message == WM_MOUSEWHEEL) {
        zds_printf(L"\n你滚动了鼠标滚轮");
    }
    // 返回false可以然后消息继续传递，true则在此处拦截
    return false;
}

void watch(MSG *pMsg)
{
    // 判断当前是否为鼠标中键消息
    if (pMsg->message == WM_MBUTTONDOWN) {
        zds_printf(L"\n你按下了鼠标中键");
    }
}

void initapp()
{
    ...
    // 注册钩子函数
    zcedRegisterFilterWinMsg(filter);
    zcedRegisterWatchWinMsg(watch);
}

void unloadapp()
{
    ...
    // 移除钩子函数
    zcedRemoveFilterWinMsg(filter);
    zcedRemoveWatchWinMsg(watch);
}
