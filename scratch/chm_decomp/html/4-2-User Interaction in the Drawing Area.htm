绘图区用户交互

说明

本章节将介绍如何通过命令行输入提示用户进行一些简单的绘图区交互以获取一些图形信息，如在界面上获取点坐标，角度，一段距离等。

用户交互函数介绍

下面表格列举了常见的几种绘图区交互的函数，后续文章将逐一演示如何使用这些函数。

函数名 作用 提示选项类 提示结果类
zcedGetAngle() 提示用户输入一个角度 PromptAngleOptions PromptDoubleResult
zcedGetCorner() 提示用户拾取矩形角点 PromptCornerOptions PromptPointResult
zcedGetDist() 提示用户输入一段距离 PromptDistanceOptions PromptDoubleResult
zcedGetPoint() 提示用户输入一个点 PromptPointOptions PromptPointResult
zcedEntSel() 提示用户选择一个实体 PromptEntityOptions PromptEntityResult

获取一个角度zcedGetAngle()

void getAngle()
{
	zds_real dAngle = 0.0;
	if (zcedGetAngle(NULL, _T("\nPick the first point"), &dAngle) == RTNORM)
		zcutPrintf(_T("\nThe Angle is %g"), dAngle);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用在绘图界面选择一个点"Pick the first point:"，假设用户选择0,0点，后续系统提示客户选择第二点，假设用户选择了100,100坐标，最终命令行输出：“The angle is 0.785398163397448”。

注：角度计算的是0,0到100,100与X坐标轴行程的角度，返回值为弧度制。

获取矩形角点zcedGetCorner()

void getCorner()
{
	zds_point ptBase = { 0,0,0 };
	zds_point zdsPt;
	if (zcedGetCorner(ptBase, _T("\nPick the corner:"), zdsPt) == RTNORM)
		zcutPrintf(_T("\nThe Point is (%g, %g, %g)"), zdsPt[X], zdsPt[Y], zdsPt[Z]);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用在绘图界面选择一个点"Pick the corner: "，假设用户选择100,100点，后续，最终命令行输出：“The Corner Point is (100, 100, 0)”。

获取一段距离zcedGetDist()

void getDist()
{
	zds_real dRet = 0.0;
	if (zcedGetDist(NULL, _T("\nPick First point:"), &dRet) == RTNORM)
		zcutPrintf(_T("\nThe distance is %g"), dRet);
	else
		zcutPrintf(_T("\nFailed!"));
}

运行结果：

执行命令提示用在绘图界面选择一个点"Pick First Point: "，假设用户选择0,0点，后续系统提示选择第二点假设用户选择100,0点，最终命令行输出：“The distance is 100”。

获取一个点zcedGetPoint()

void getPoint()
{
	zds_point zdsPt;
	int nRet = zcedGetPoint(NULL, _T("\nSelect a Point："), zdsPt);
	if (nRet == RTNORM)
		zcutPrintf(_T("\nThe point is (%g,%g,%g)"), zdsPt[X], zdsPt[Y], zdsPt[Z]);
	else if (nRet == RTCAN)
		zcutPrintf(_T("\nYou have cancelled!"));
	else
		zcutPrintf(_T("Failed!"));
}

运行结果：

执行命令提示用在绘图界面选择一个点"Select a Point: "，假设用户选择100,1000点，最终命令行输出：“The Point is (100, 100, 0)”。

拾取一个实体GetEntity()

void entSelEx()
{
	zds_name entName;
	zds_point zdsPt;
	int nRet = zcedEntSel(_T("\nSelect a Entity:"), entName, zdsPt);
	if (nRet == RTNORM)
	{
		ZcDbObjectId objId;
		Zcad::ErrorStatus es = Zcad::eOk;
		if ((es = zcdbGetObjectId(objId, entName)) != Zcad::eOk)
		{
			zcutPrintf(_T("\nErrorStatus = %s"), zcadErrorStatusText(es));
			return;
		}

		ZcDbEntity* pEnt = nullptr;
		if ((es = zcdbOpenZcDbEntity(pEnt, objId, ZcDb::kForRead)) != Zcad::eOk)
		{
			zcutPrintf(_T("\nErrorStatus = %s"), zcadErrorStatusText(es));
			return;
		}

		zcutPrintf(_T("\nThe Entity you select is %s"), pEnt->isA()->name());
		pEnt->close();
	}
}

运行结果：

在绘图区绘制一个圆，执行EntSelTest命令提选择一个实体"Select an Entity: "，选择刚刚绘制的圆， 命令行输出：“The Entity you select is ZcDbCircle”。
